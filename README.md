# 🏎️ NEON RUSH · 极速狂飙 3D

> 一款基于 **Three.js** 的浏览器 3D 赛车游戏，单 HTML 文件即可运行，零安装、零依赖（除 CDN 加载的 Three.js）。

内置 **6 种酷炫道具**、**暴力摩托式的干扰破坏机制**（EMP 电磁脉冲、追踪导弹、油渍陷阱……）、**4 段动态切换的赛道场景**、**程序合成的电子音乐与音效**，以及带橡皮筋机制的 AI 对手。完整体验「开始 → 3 圈竞速 → 结算」流程。

---

## ✨ 特性

- **🛣️ 多场景环形赛道** — 一条赛道穿越 4 种主题环境：暖色沙漠 → 紫色霓虹城 → 冷色雪原 → 幽暗发光隧道。天空、雾、灯光随场景实时切换。
- **⚡ 6 种道具 + 破坏机制**（核心爽点）
  | 道具 | 效果 |
  |------|------|
  | **EMP 电磁脉冲** | 发射追踪冲击波，命中瘫痪对手 2 秒（失控打转 + 蓝火花 + 屏幕震动） |
  | **追踪导弹** 🚀 | 锁定前方最近对手，爆炸击飞 |
  | **油渍陷阱** 🛢 | 地面铺设，压中者打滑旋转 |
  | **氮气加速** 🔥 | 2 秒极速 + 蓝色尾焰 |
  | **能量护盾** 🛡 | 免疫下一次攻击 |
  | **强力磁铁** 🧲 | 远距离吸附前方道具盒 |
- **🤖 4 个 AI 对手** — 沿赛道寻路、主动使用道具、互相攻击，带橡皮筋机制（落后加速、领先减速）保持竞争紧张感。
- **🎆 11 种粒子特效** — 爆炸火球、EMP 电弧扩散、导弹拖尾、漂移火花、加速尾焰、拾取爆裂、碰撞火花等。
- **🎵 Web Audio 程序合成** — 130 BPM 电子背景乐（贝斯 + 鼓点 + 主旋律）、随速度变频的引擎声、9 种战斗音效。无需任何音频文件。
- **📊 完整 UI** — 开始菜单 → 3-2-1-GO 倒计时 → 实时 HUD（排名 / 圈数 / 速度表 / 小地图 / 道具栏）→ 结算界面（可重玩）。
- **📷 第三人称追尾视角** — FOV 随速度变化营造速度感，按 `C` 切换远景俯视。

## 🎮 玩法

### 操作

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 油门加速 |
| `S` / `↓` | 刹车 / 倒车 |
| `A` / `D` | 左右转向 |
| `空格` | 漂移过弯（高速时有效） |
| `Shift` | 使用当前道具 |
| `B` | 手动氮气加速（消耗氮气槽） |
| `C` | 切换视角 |

### 目标

拾取赛道上的发光道具盒获取随机道具，用道具干扰并超越 4 名 AI 对手，**3 圈定胜负**，率先冲过终点线夺冠！

## 🚀 运行

### 方式一：直接打开
双击 `racing3d.html` 即可在浏览器中运行（需联网加载 Three.js CDN）。

### 方式二：本地服务器（推荐，避免浏览器本地文件限制）
```bash
# 在项目目录下
python -m http.server 8000
# 然后浏览器访问 http://127.0.0.1:8000/racing3d.html
```

> 支持所有现代浏览器（Chrome / Edge / Firefox），推荐 Chrome 获得最佳性能。

## 🛠️ 技术栈

- **[Three.js](https://threejs.org/) r0.180** — 3D 渲染（WebGL），通过 jsDelivr CDN + importmap 引入
- **Web Audio API** — 全部音乐与音效实时程序合成，零外部音频资源
- **原生 HTML/CSS/JS** — 单文件交付，无构建工具、无打包步骤

### 核心实现要点

- **赛道**：`CatmullRomCurve3` 生成环形中心曲线，沿线挤出路面 Mesh，按进度分段着色对应 4 种主题
- **车辆物理**：简化街机物理（加速度 / 转向 / 漂移 / 摩擦），非真实物理引擎，注重手感
- **进度与排名**：用赛道曲线参数 `t`（0~1）追踪每辆车进度，过线检测配合「首次过线标记」避免起跑误判
- **AI**：赛道寻路 + 状态机 + 橡皮筋（rubber-band）难度平衡
- **粒子系统**：基于 `THREE.Points` 的对象池，复用 600 粒子上限
